# Самопроверка и исправления

Первый вариант проверил командой:

```bash
python -m pytest -v --cov=app --cov-report=term-missing
```

Получил 67 passed и 3 failed. Все сценарные тесты прошли, ошибки нашла
генерация запросов по OpenAPI. Зафиксировал замечания в PR до исправления кода.

| Проблема | Причина | Исправление |
| --- | --- | --- |
| Неполный Allow в ответе 405 | Для одного пути описано несколько маршрутов, а роутер берёт методы первого совпадения | Собрал методы всех маршрутов, совпавших по пути; добавил проверки обоих ресурсов |
| `priority: 4.0` даёт 422 | Строгий int в Pydantic отличается от семантики integer в JSON Schema | Нормализовал числа без дробной части; строки, bool и дроби по-прежнему дают 422 |
| Неописанный ответ 400 | Неверная кодировка тела вызывает ошибку разбора раньше валидации модели | Описал 400 в POST и PUT, добавил проверки отказа без изменения данных |

При просмотре контракта также заметил, что Location проверяется в сценарии,
но не описан в OpenAPI. Добавил заголовок в ответ 201 и обновил спецификацию.

Проверки генератора оставил включёнными. Регрессионные тесты проверяют приём
целых JSON-чисел через POST и PUT, полный Allow и отсутствие изменений после 405.

После исправлений получил **78 passed**, покрытие строк и ветвей кода API —
**100%** на Python 3.14.5. Линтер, форматирование и сверка OpenAPI проходят.

Это самопроверка автора. Независимое ревью должен выполнить другой разработчик;
комментарий автора и зелёный CI не считаю его одобрением.
